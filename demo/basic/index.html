Spritemap Flags with <use>

Icons from virtual:spritemap

No route written by hand. virtual:spritemap exports { url, name, prefix, icons, href }, so JavaScript can build a reference without knowing the route option or repeating the prefix. An id always names one instance by its route.name; the bare virtual:spritemap is simply that id for the default name, which is why the second instance here is virtual:spritemap/__flags. Neither changes meaning as instances are added, and an id naming none of them lists the ones that exist.

Every icon, from spritemap.icons

icons lists the ids sorted and unprefixed, so it matches the generated Icons type and composes with href.

The string forms: ?url and ?raw

Vite's own spellings. virtual:spritemap?url is the url alone, and virtual:spritemap?raw is the spritemap markup — useful for injecting the sprite into the page yourself. Note ?raw inlines the whole sprite into the bundle while the asset file is still emitted, so it ships twice unless output is false.
